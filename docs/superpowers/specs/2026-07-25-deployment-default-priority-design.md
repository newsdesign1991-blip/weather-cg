# 새 배포 기본값 우선 적용 설계

## 목표

`default-presets.js`가 바뀐 첫 실행에는 브라우저에 남아 있는 현재 작업과 개인 저장 배치를 제거하고 새 배포 기본값을 우선 적용한다.

## 동작

- `window.WCG_DEFAULTS`의 결정적 지문을 계산해 `localStorage`에 저장한다.
- 저장된 지문과 현재 지문이 다르면 `wcg_work`와 `wcg_presets`를 모두 제거한다.
- 지문 검사는 작업 자동복원보다 먼저 실행한다.
- 같은 배포 지문에서는 저장 데이터를 제거하지 않으므로 이후 자동저장과 개인 배치 저장은 정상 유지된다.
- 기본값 파일이 없거나 비어 있으면 저장 데이터를 제거하지 않는다.

## 검증

- 첫 실행과 배포 변경 시 두 저장 키가 제거되는지 검사한다.
- 같은 배포본의 재실행에서는 저장값이 유지되는지 검사한다.
- 기본값이 비어 있을 때 저장값이 유지되는지 검사한다.
