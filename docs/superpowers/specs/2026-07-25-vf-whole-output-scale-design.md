# VF 출력화면 전체 크기 조절 설계

## 목적

노말 VF 출력 화면의 모든 방송 출력 요소를 한 덩어리로 확대·축소할 수 있게 한다. 사용자는 사이드바의 수치 조절과 캔버스의 크기 핸들을 모두 사용할 수 있어야 하며, 설정값은 개인 화면 기본값과 배포용 `default-presets.js`에 저장되어야 한다.

## 범위

전체 크기 조절 대상은 다음과 같다.

- 파란색 배경판
- 지도와 색칠
- 도서 박스
- 산 표시
- 제목과 단위
- 라벨
- 범례
- 제목 바와 제목 바 그림자

작업용 가상 영상 배경, 가이드, 선택 외곽선과 조절 핸들은 확대·축소 대상에서 제외한다. 이 기능은 `1920x1080-vf` 화면에서만 표시하고 적용한다.

## 조작 방식

사이드바에는 VF 화면에서만 보이는 `전체 크기` 조절 항목을 둔다.

- 범위: 50~150%
- 기본값: 100%
- 조절 단위: 1%
- 슬라이더와 현재 퍼센트 값을 함께 표시한다.

캔버스에서는 이동 모드일 때만 전체 배경판의 선택 외곽선과 크기 핸들을 표시한다. 파란색 배경판의 오른쪽 위 모서리를 고정 기준점으로 삼고, 왼쪽 아래 핸들을 끌어 전체 크기를 비율 고정으로 조절한다. 드래그 도중 값은 50~150%로 제한하며, 한 번의 드래그는 실행 취소 기록 한 단계로 처리한다.

## 렌더링 구조

VF 출력 요소를 하나의 SVG 부모 그룹 `L_vfScale` 아래에 배치하고, 부모 그룹에 오른쪽 위 기준의 균일 스케일 변환을 적용한다. 현재 VF 진입 애니메이션의 이동·페이드 변환과 전체 크기 변환이 서로 덮어쓰지 않도록 별도의 중첩 그룹에 각각 책임을 나눈다.

전체 크기 변환은 화면 미리보기뿐 아니라 다음 출력 경로에도 동일하게 적용되어야 한다.

- 정지 PNG 및 레이어별 출력
- PNG 시퀀스
- 알파 MOV
- AE 전송 및 AE 레이어 구성
- VF 진입 애니메이션

선, 글자, 그림자와 요소 사이 간격도 부모 그룹의 배율에 따라 함께 변한다.

## 상태와 공유 규칙

상태에는 VF 전체 크기를 나타내는 배율 값을 추가한다. 사용자에게는 두 종류의 값만 존재한다.

1. 일반 VF 전체 크기
2. 특보+해상 VF 전체 크기

일반 VF의 밝은 모드와 어두운 모드는 같은 값을 공유한다. 특보+해상 VF도 밝은 모드와 어두운 모드가 같은 값을 공유한다. 일반 VF와 특보+해상 VF의 값은 서로 독립적이다.

지도 종류나 CG 밝기 전환, 프리셋 적용 과정에서 이 공유 규칙이 유지되어야 한다. 과거 프로젝트나 프리셋에 값이 없으면 100%를 적용한다.

## 저장과 배포

전체 크기 값은 다음 경로에 포함한다.

- 실행 중 상태와 새로고침 복원
- 실행 취소·다시 실행
- 프로젝트 JSON 저장·불러오기
- `현재 배치를 이 화면 기본값으로`
- `저장한 배치들을 모두의 기본값으로 굽기`
- 배포용 `default-presets.js`

`현재 배치를 이 화면 기본값으로` 저장할 때 현재 VF 그룹의 공유값을 저장한다. `default-presets.js`를 구울 때도 일반 VF와 특보+해상 VF 각각의 값이 밝은/어두운 프리셋에 일관되게 포함되어야 한다.

## 사용자가 만든 최종 기본값 반영 절차

사용자가 앱에서 위치와 전체 크기를 최종 조정한 뒤 굽기 기능으로 JS 파일을 다운로드한다. 사용자가 그 파일을 제공하며 기본값 반영을 요청하면 다음 절차로 처리한다.

1. 파일이 `window.WCG_DEFAULTS` 형식인지 확인한다.
2. 필수 프리셋 키와 값의 범위를 검사한다.
3. VF 일반·특보+해상 공유값이 밝은/어두운 프리셋에서 일관적인지 확인한다.
4. 프로젝트의 `default-presets.js`에 반영한다.
5. 앱 로딩, 화면 전환, 렌더링과 기존 프리셋 호환성을 검증한다.
6. 변경사항을 커밋하고 GitHub 원격 저장소에 푸시한다.
7. 반영된 브랜치와 커밋을 사용자에게 알린다.

다운로드된 파일 이름이 `default-presets.js`가 아니어도 내용이 올바르면 동일하게 처리한다. 형식이나 값이 잘못된 경우 기존 기본값을 덮어쓰지 않고 오류 내용을 알린다.

## 오류 처리와 호환성

- 배율이 없거나 숫자가 아니면 100%를 사용한다.
- 배율이 범위를 벗어나면 50~150% 안으로 제한한다.
- 일반 화면에서는 VF 배율 상태를 렌더링에 적용하지 않는다.
- 과거에 저장된 프로젝트와 배포 프리셋은 수정 없이 열려야 한다.
- 프리셋 전환 중 한 그룹의 값이 다른 그룹으로 섞이지 않아야 한다.

## 검증 기준

- 사이드바 조절과 캔버스 핸들이 실시간으로 동기화된다.
- 오른쪽 위 기준점은 배율을 바꿔도 움직이지 않는다.
- 파란 배경판과 제목 바를 포함한 모든 출력 요소가 동일 비율로 변한다.
- 이동 모드가 아니면 전체 크기 외곽선과 핸들이 보이지 않는다.
- 일반 VF의 밝은/어두운 모드가 같은 값을 사용한다.
- 특보+해상 VF의 밝은/어두운 모드가 같은 값을 사용한다.
- 일반 VF와 특보+해상 VF는 서로 다른 값을 유지한다.
- 새로고침, 프로젝트 저장·불러오기, 화면 기본값 저장·적용 후 값이 유지된다.
- 굽힌 `default-presets.js`를 새 상태에서 불러와도 같은 배치가 재현된다.
- 정지 화면, 애니메이션, PNG 시퀀스, 알파 MOV와 AE 결과의 크기가 미리보기와 일치한다.
- 기존 VF 진입 이동·페이드 애니메이션이 전체 크기 변환과 함께 정상 동작한다.
