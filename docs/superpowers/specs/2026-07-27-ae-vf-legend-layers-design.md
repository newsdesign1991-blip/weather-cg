# AE VF 제목 바·범례 레이어 디자인

## 목적

AE로 보낸 VF 화면에서 지도 경계선이 제목 바 위로 올라오지 않게 하고, 범례의 색상 네모와 문구를 AE에서 각각 편집할 수 있게 한다.

## 확인된 원인

- 현재 `aeBaseBlob()`은 지도와 함께 `L_vfBar`, `L_legend`를 한 PNG에 굽는다.
- 이후 `색칠`, `브러쉬`, `경계선`, `산` 레이어가 그 PNG 위에 추가된다.
- 따라서 나중에 추가된 한반도 경계선이 이미 구워진 제목 바와 범례 위에 나타난다.
- 범례는 통이미지 안에 있으므로 AE에서 항목별 편집이 불가능하다.
- 제목 글자는 별도 AE 텍스트로 재생성되지만 범례는 SVG 래스터 결과를 사용해 서로 다른 좌표·폰트 배치 경로를 탄다.

## AE 레이어 순서

메인 컴프의 아래에서 위 순서는 다음과 같다.

1. 배경·지도
2. 특보 색칠
3. 브러쉬
4. 경계선
5. 산
6. VF 제목 바
7. 제목 텍스트
8. 범례 프리컴프

`배경·지도` PNG에서는 `L_vfBar`, `L_title`, `L_legend`를 모두 제거한다. 제목 바는 지도 관련 레이어가 모두 생성된 뒤 별도 투명 PNG 레이어로 추가하여 지도와 경계선을 완전히 덮는다.

## 제목 바

- 웹에서 계산된 확장 높이(`vfExpandedLegend().extraH`)를 포함한 최종 `vfBarRect`를 사용한다.
- VF 전체 스케일은 기존 `L_vfScale` 변환과 동일한 우상단 기준으로 한 번만 적용한다.
- 제목 바 그림자와 배경 크롭은 웹 결과를 그대로 별도 PNG에 보존한다.
- 제목 글자는 기존처럼 편집 가능한 AE Text Layer를 유지하고 제목 바보다 위에 둔다.

## 범례 프리컴프

메인 컴프에 `범례` 프리컴프 레이어 하나를 만들고, 프리컴프 내부에는 표시 중인 각 항목마다 두 레이어를 만든다.

- `<항목명>_네모`: AE Shape Layer의 사각형
- `<항목명>_글자`: AE Text Layer

자동 범례와 수동 범례 모두 현재 SVG에 실제 렌더된 `#L_legend` 요소에서 최종 좌표를 측정한다. 각 `rect`의 위치·크기·모서리 반경·색상과 각 `text`의 위치·글자·크기·굵기·자간·색상을 수집한다. 문자열 길이로 위치를 다시 추정하지 않는다.

프리컴프의 경계는 모든 범례 요소의 합집합에 여백을 더해 계산한다. 내부 레이어 좌표는 이 경계의 좌상단을 뺀 로컬 좌표로 저장하고, 프리컴프 레이어는 원래 경계 중심에 배치한다. VF 전체 스케일은 경계와 내부 크기에 동일하게 한 번만 반영한다.

## 웹–AE 도우미 계약

웹 앱은 AE 스펙에 다음 구조를 추가한다.

```js
{
  legendComp: {
    w, h, x, y,
    items: [{
      name,
      shape: { x, y, w, h, radius, fill },
      text: { content, x, y, size, weight, track, fill }
    }]
  },
  name: "범례"
}
```

AE 도우미는 `legendComp`를 받으면 프리컴프를 만들고, 각 `shape`를 Shape Layer로, 각 `text`를 Text Layer로 생성한다. 기존 도우미가 새 필드를 받지 않은 작업과 기존 `labelComp`, 일반 텍스트·이미지 레이어 계약은 그대로 유지한다.

## 오류 처리

- 범례가 꺼져 있거나 표시 항목이 없으면 `legendComp`를 보내지 않는다.
- 범례 DOM을 측정할 수 없으면 기존처럼 범례를 통이미지로 굽지 않고, AE 전송을 중단해 “범례 레이어 측정 실패”를 보여준다.
- 제목 바가 꺼져 있으면 제목 바 PNG를 만들지 않는다.

## 검증

- `aeBaseBlob()`에서 제목 바·제목·범례가 제외되는지 검사
- 제목 바 레이어가 경계선·산 뒤, 제목·범례 앞에 추가되는지 검사
- 자동·수동 범례의 1개, 2개, 3개 이상 배치에서 DOM 좌표가 AE 스펙에 반영되는지 검사
- 범례 항목마다 Shape Layer와 Text Layer가 생성되는지 AE 도우미 계약 검사
- VF 스케일 83%, 86%, 100%에서 중복 스케일이 없는지 검사
- 기존 전체 테스트와 AE 전송 스펙 테스트 실행
