# 출력 화면·지도 종류 확인 선택 설계

## 목표

출력 화면과 지도 종류에서 현재 적용값과 사용자가 방금 고른 후보를 분리하고, 명시적인 적용 버튼을 눌러야 실제 화면이 바뀌도록 한다.

## 상호작용

- 메뉴를 열면 미리 선택된 파란 카드가 없다.
- 카드를 누르면 후보 카드에 파란색·체크·상승 모션이 나타나고 긴 적용 버튼이 활성화된다.
- 적용 버튼을 누르면 실제 상태를 변경하고 메뉴를 닫는다.
- 시작 안내 화면의 완료 표시는 카드 선택이 아니라 적용 완료 시점에 갱신한다.
- 출력 화면 메뉴의 저장 배치 설명 목록은 제거한다.
- 개인 배치 저장과 배포 기본값 초기화는 별도 제목과 구분선으로 분리한다.

## 검증

- 카드 클릭만으로 `S.res`와 `S.style`이 변경되지 않는지 검사한다.
- 적용 함수가 후보를 실제 상태에 반영하고 메뉴를 닫는지 검사한다.
- 시작 안내 완료 처리가 적용 함수에서만 호출되는지 검사한다.
