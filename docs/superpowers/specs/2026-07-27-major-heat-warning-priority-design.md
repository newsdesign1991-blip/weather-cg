# 폭염 중대경보 기본 우선순위 설계

## 목표

폭염 경보와 폭염 중대경보가 함께 들어오면 폭염 중대경보를 기본적으로 더 높은 우선순위에 둔다.

## 동작

- 특보 데이터를 처음 정렬할 때 `폭염 중대경보`가 `폭염 경보`보다 앞선다.
- 이 기본 순서는 들어온 특보 목록, 자동 범례, 지도 색칠 레이어 순서에 동일하게 반영한다.
- 같은 지역에 두 특보가 겹치면 폭염 중대경보 색이 최종적으로 보인다.
- 사용자가 드래그로 바꾼 현재 순서는 기본 순서보다 우선한다.
- 저장된 기존 프로젝트의 사용자 지정 순서는 변경하지 않는다.
- 다른 특보의 기존 우선순위는 변경하지 않는다.

## 검증

- 기본 우선순위에서 폭염 중대경보가 폭염 경보보다 앞서는 테스트
- 지도 색칠 순서에서 폭염 중대경보가 최종 레이어가 되는 테스트
- 사용자가 수동으로 바꾼 순서가 유지되는 테스트
- 전체 회귀 테스트
