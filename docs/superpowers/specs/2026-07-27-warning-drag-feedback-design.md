# 특보 순서 드래그 피드백 디자인

## 목적

들어온 특보의 레이어 우선순위를 드래그로 바꿀 때 실제 삽입 위치를 분명히 보여주고, 각 특보 항목을 시각적으로 구분한다.

## 상호작용

- 드래그 중 포인터가 항목의 위쪽 절반에 있으면 해당 항목 위에 파란 삽입선을 표시한다.
- 아래쪽 절반에 있으면 해당 항목 아래에 파란 삽입선을 표시한다.
- 삽입선 가운데에는 작은 방향 표시를 두어 놓일 위치를 강조한다.
- 드래그하는 원본 항목은 투명도를 낮춘다.
- 드롭 결과는 표시된 삽입 위치와 정확히 일치해야 한다.
- 드롭, 취소, 목록 밖 이탈 시 모든 드래그 강조를 제거한다.
- 순서 변경은 기존 동작처럼 현재 조회 결과에만 적용하고 다음 특보 조회 때 기본순서로 돌아간다.

## 간격

- 특보 항목 사이에 6px 간격을 둔다.
- 목록 제목과 첫 항목의 기존 여백은 유지한다.
- 항목 내부 크기와 색상 편집·눈 버튼 동작은 변경하지 않는다.

## 구현 범위

- `index.html`의 특보 목록 렌더링과 드래그 이벤트만 수정한다.
- 삽입 위치 계산은 별도 순수 함수로 만들어 테스트한다.
- CSS 클래스로 위·아래 삽입선, 드래그 원본 투명도, 항목 간격을 표현한다.

## 검증

- 위쪽 절반과 아래쪽 절반의 삽입 인덱스 계산
- 아래 방향 이동 시 인덱스 보정
- 드래그 관련 CSS 클래스와 6px 간격 존재
- 기존 특보·VF·공지 테스트 전체 회귀 실행
